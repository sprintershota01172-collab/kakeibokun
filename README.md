# カケイボくん — オフライン家計簿 v0.1

出張立替金・個人支出・夫婦共通支出・カードの引落日を整理するための家計簿PWAの **初期版** です。日本語UI、グレージュ×深緑、Meiryo UI、5タブ固定、ページ内スクロールなしを基本とします。

## 現在動作する機能
- 支出・収入のテンキー入力、カテゴリー、個人／夫婦共通、支払者
- 利用月ベースの家計集計とカレンダーによる履歴参照・編集・削除
- 複数カードの締め日・引落日登録、一括払い請求予定の概算
- 銀行口座の残高スナップショットと、登録済みカード引落後の簡易残高見込み
- 月間予算・固定費の毎月自動登録（アプリ起動時）
- 夫婦共通の変動費50:50・固定費の設定割合での差額試算（精算機能なし）
- JSONの手動バックアップと復元、CSV出力
- Service Workerによるオフライン起動と端末内保存
- 未記録日のアプリ内確認表示

## 最重要：セキュリティと社内規定
- 現在リポジトリは **公開設定** です。アプリのソースコードには個人データや秘密鍵を保存しないでください。社外公開やGitHub Pages公開の前にプライバシーとアクセス制御を確認してください。
- データは端末のブラウザの `localStorage` に保存されます。クラウドへ送信せず、夫婦共有や端末間同期もしません。ブラウザデータを消すと失われます。JSONバックアップを定期的に取得してください。
- `localStorage` は暗号化保管ではありません。共有端末では使わないでください。
- **会社の経費データを個人アプリに保存することは禁止**、個人の出張立替額も保存可否未確認という要件に従い、出張タブで関連データの登録を停止しています。業務領収書、出張先、経費明細、会社機密情報を入力しないでください。
- カードの引落見込みは登録した取引・締め日設定からの *推定* であり、公式請求額ではありません。明細未登録・請求確定の差異・土日祝の金融機関引落繰延・返金などは反映されません。
- 銀行残高は手動入力した確認済み残高を基準に一部の記録済み出入金のみを反映する概算で、実残高を保証しません。
- 再発行されたカードや締め日変更は過去取引に影響します。長期利用前に取引ごとに請求サイクルを保存する構造へ改善が必要です。

## 起動
静的ファイルだけで動くため、Node.jsは不要です。リポジトリをダウンロードし、次のようにローカルサーバーで開けます。

```bash
python3 -m http.server 8000
```

ブラウザから `http://localhost:8000/` にアクセスしてください。PWAインストールはHTTPSまたはlocalhostが必要です。公開URLやGitHub Pagesはまだ設定していません。

## ディレクトリ
- `index.html`: 画面の土台
- `styles.css`: レスポンシブ・非スクロールUI
- `app.js`: 状態管理、支出、カード、家計、バックアップ
- `manifest.webmanifest`, `sw.js`, `icon.svg`: PWA
